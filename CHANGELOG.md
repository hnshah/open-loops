# Changelog

## 0.2.0 - 2026-08-22

Flesh out the public repository around the portable skill without broadening the job.

- add full documentation set for state reconstruction, architecture, adapters, benchmarking, testing, routine mode, portability, FAQ, and roadmap
- add architecture decision records for the core product laws
- add JSON Schemas for normalized evidence, open loops, feedback, predictions, and optional persistent state
- add email, chat, calendar, cross-source, personalization, and quiet-run examples
- add optional routine and ledger references plus packaged skill assets
- add Claude, Codex, and `.agents` distribution metadata around one canonical skill package
- add host/model validation matrix and real-world scorecard
- add portability and package validation scripts
- add governance, code of conduct, CODEOWNERS, PR template, and compatibility/documentation issue templates
- strengthen CI and repository validation

No model-performance claim is introduced in this release.
