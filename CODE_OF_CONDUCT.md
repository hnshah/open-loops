# Code of Conduct

Open Loops is a public experiment about agent judgment, unfinished work, and evidence-backed state reconstruction.

Contributions should make the method clearer, safer, more portable, or more correct.

## Expectations

- Be specific about observed behavior and evidence.
- Critique ideas and implementations without attacking people.
- Protect privacy. Never post real inbox, chat, calendar, CRM, meeting, customer, or confidential company content.
- Sanitize examples to the minimum structure needed to reproduce a failure.
- Do not use issues or pull requests to publish secrets, credentials, private links, or personal information.
- Separate measured results from speculation.
- Do not manufacture benchmark claims.

## Enforcement

Maintainers may edit, hide, or remove contributions that expose private data, contain abuse, or create security risk. Repeated or serious violations may result in participation restrictions.

Security-sensitive reports should follow [`SECURITY.md`](SECURITY.md) rather than a public issue.
