# Roadmap

This roadmap is ordered by evidence, not feature count.

## Now — prove the scan

- run controlled email-only and chat-only tests
- measure top-five precision and importance
- turn false positives and missed loops into evals
- improve completion detection before adding new categories
- validate install and trigger behavior across major Agent Skills hosts
- publish benchmark results only when the protocol is repeatable

## Next — prove cross-source state

- test obligations that begin in one source and close in another
- formalize adapter behavior around source scope and evidence links
- test calendar-plus-message preparation inference
- harden ownership transfer and rescheduling cases
- expand the public suite with difficult sanitized failures from real use

## Then — prove learning

- persist lightweight user-specific rules where the host supports it
- test whether run two improves after explicit corrections
- measure personalization errors separately from universal reasoning errors
- keep personal rules out of the public skill

## After that — prove continuity

- introduce optional loop ledgers
- carry forward unresolved high-confidence items
- check old loops for closure each run
- test daily versus weekly cadence
- measure seven-day delegation retention

## Only after trust — expand autonomy

- prepare replies, briefs, research, and files
- create review-ready queues
- execute external actions only with explicit approval
- consider recurring ownership only for proven configurations

## Deliberately not on the roadmap yet

- universal task management
- autonomous inbox handling
- “AI chief of staff” positioning
- large workflow engines inside this repo
- proprietary connectors embedded in the core skill
- automatic external writes
- public collection of private user data

The repository should get deeper before it gets broader.
